# Private firmware inputs

Place your own original `LZ5014_R.djf` here, or pass `--source /path/to/file`
to the builder. Manufacturer firmware is not distributed by this project.
The builder accepts only the exact SHA-256 in the supported profile.

Files in this directory are ignored by Git except this README. Do not include
original firmware, device serial numbers, credentials, or private captures in
source archives or public issues.
